The user-requested UI/UX Pro Max workflow informed its monochrome liquid-glass surfaces, original SVG wave sculpture, and motion system. Product images are screenshots of the actual packaged app.

Production URL: https://noir-audio-orpin.vercel.app

Vercel project: `noir-audio`, ID `prj_8cAeB5fLFoBGWQYW3K8hofI2P0s9`. Only `Website/public` is served. - The original SVG, actual app screenshot resolution, backdrop blur, and pointer-driven sculpture movement.
- Scroll reveals reaching a visible state across desktop and phone pages.
- No horizontal overflow on every page at 320, 375, 768, 1024, 1440, and 1920 px, plus landscape layout.
- Studio, Effects, and Routing tabs: pointer selection, matching panels, arrow keys, Home, End, and wrapping.
- Mobile navigation: keyboard access, Escape, restored button focus, outside clicks, link selection, and breakpoint changes.
- Keyboard FAQ disclosures, working native links/downloads without JavaScript, and visible fallback content.
- Reduced motion disabling introductions, scroll reveals, pointer parallax, smooth scrolling, and document transitions.
- Internal links, routing anchors, the sitemap, and absence of JavaScript/console errors.
- Actual browser app download; HTTP delivery, SHA-256 verification, and equality with local app/driver/source artifacts.

Full-page and viewport screenshots were reviewed at desktop and mobile sizes. Tests use the installed Chromium headless browser; they are not a formal accessibility certification or a claim that every browser/device has been tested. Unsupported native page transitions fall back to normal navigation. Glass has an opaque fallback when backdrop filtering is unavailable.
