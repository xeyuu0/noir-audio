Is Windows included?+

Yes. A native x64 preview is available for Windows 10 (1703+) and Windows 11, with a setup installer and portable ZIP. It uses WASAPI and shares the Mac build’s audio processing. Per-app capture needs Windows 11. Read the Windows guide for feature differences and virtual-cable setup.

Does it work on my Mac?+

This preview is built for Apple Silicon and targets macOS 14.2 or later. It has been verified on macOS 27.2. Older supported macOS versions and Intel Macs have not been validated; an Intel build is not included.

Why does macOS show a warning?+

The preview is not Developer ID signed or notarized. If you choose to trust it after reviewing the source and checksum, follow the linked Apple instructions in the installation guide. Managed Macs can enforce additional restrictions.

Do I need the virtual drivers?+

Install them to send your mix into another app through NOIR Microphone or bring another app’s output in through NOIR Loopback. Mixing physical inputs, internal recording, and soundboard playback do not require these virtual devices.

Can I use it for broadcasting?+

Yes, with a separately selected FFmpeg executable and a compatible server. The Mac build supports Icecast, SHOUTcast v1, and RTMP(S), tested against local receivers. Windows preview supports Icecast and RTMP(S). Public services remain unverified, and some RTMP services require video. See the release boundaries.

Is NOIR free and open source?+

Yes. NOIR’s original code is GPL-3.0-or-later. The release includes BlackHole’s GPLv3 HAL foundation and OctopusEAX’s MIT-licensed DSP, with their source and original licenses.
