GETTING STARTED / WINDOWS

A new home
for your sound.

Native Windows controls. WASAPI audio. The same processing at the heart of NOIR.

Windows x64 preview. For Windows 10 (1703+) and Windows 11. Per-application capture needs Windows 11. This installer is unsigned. Audio-device compatibility and virtual-cable workflows still need hardware validation.

Install the Windows studio

  1. Download the Windows setup installer, or use the portable ZIP.
  2. Compare the file with the published SHA-256 checksum. This is an unsigned preview, so Windows may display an unknown-publisher or SmartScreen warning. Review the source before deciding whether to run it.
  3. Setup installs NOIR for your Windows account and adds a Start menu shortcut. It does not install audio drivers. For the portable version, extract the whole folder before opening NOIR Audio.exe.
  4. Open Routing, choose a microphone, and select an output clock. Assign your Main destination, enable the source sends you want, then press Start audio.

Send your mix into another app

Windows uses its own virtual audio drivers. Install a cable separately from its vendor, such as VB-CABLE. The Mac NOIR drivers cannot run on Windows.

  1. In NOIR, set Main → CABLE Input, the cable’s playback endpoint.
  2. Enable Microphone → Main and, if wanted, Soundboard → Main.
  3. In Discord, OBS, or another receiving app, choose CABLE Output as its microphone or recording input.
  4. Use headphones for monitoring. Keep the receiving app’s return audio out of the mix being sent back to it.

Each bus uses a separate output endpoint. Additional independent destinations may require additional virtual cables. Stop NOIR’s audio before changing devices.

Capture system or application audio

Application Audio offers system-output loopback and per-application capture. Choose one source, then route the Application audio strip to a bus. Process capture requires Windows 11, and your app selection is cleared on relaunch because Windows process identifiers change. Protected content may be silent.

NOIR prevents using the captured system output as a bus destination. If a device disconnects, audio stops with an error; choose a replacement and restart explicitly.

Clips, recording, and streaming

Import audio into 48 soundboard pads. Windows Media Foundation decodes supported local files. Recording writes stereo 48 kHz, 24-bit WAV, with AAC export and a 5–120 second replay buffer. Use Recover interrupted takes if a recording ended unexpectedly.

Broadcasting supports Icecast MP3 and RTMP(S) AAC through a separately selected FFmpeg executable. Stream credentials stay in memory. Windows preview does not include SHOUTcast v1 or automatic broadcast reconnect. Windows N editions need the Media Feature Pack for decoding and AAC export.

Verify a Windows download

Get-FileHash .\NOIR-Audio-0.1.0-Windows-x64-Setup.exe -Algorithm SHA256

Compare the result with SHA256SUMS.txt. A checksum verifies the file’s bytes; it does not provide publisher signing.

Your files stay yours

Settings, managed soundboard clips, and recordings live in %LOCALAPPDATA%\NOIR Audio. Uninstalling the application preserves that folder. Windows sessions reference local managed clips and use Windows device IDs; they are not interchangeable with Mac sessions.

Build or inspect it

The complete code, upstream DSP, licenses, build scripts and tests are on GitHub. Build with Visual Studio 2022 C++ tools and CMake. See the Windows README and build checks for instructions and current results.
