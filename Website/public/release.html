RELEASE NOTES / 2 NOVEMBER 2026

The first chapter.

NOIR Audio 0.1.0 brings native mixing, voice effects, virtual routing, soundboard, recording, and optional broadcasting into one macOS application.

Development preview. Apple Silicon only. Minimum deployment target: macOS 14.2. Verified host: macOS 27.2 with Xcode 27.1. The app and driver bundles are ad-hoc signed; the installer is unsigned. None of these artifacts is notarized.

What’s included

  • Native mixer: four hardware input strips, a soundboard source, a selected application source, and four independent stereo buses with gain, balance, mute, solo, and routing.
  • Voice processing: original OctopusEAX algorithms, 15 reverb environments, 42 masks, pitch and voice shaping, isolation, gate, EQ, filtering, compression, and output limiting. Reorder effects without restarting audio.
  • Virtual devices: a BlackHole-based stereo microphone and 16-channel loopback, with installation, detection, repair, and removal controls.
  • Soundboard: 48 pads, owned copies of imported files, clip replacement and removal, volume, fade, looping, and shortcuts for the first nine visible pads.
  • Recording: 24-bit WAV, a 5–120 second replay buffer, native AAC export, and recovery of interrupted takes.
  • Broadcasting: Icecast, SHOUTcast v1, and RTMP(S), optional external encoding, bounded retries, and an independent broadcast mix.
  • Daily controls: setup assistant, menu bar controls, saved sessions and presets, customizable shortcuts, and optional global hotkeys.

Reliability fixes

The launch crash was traced to high-frequency meter updates repeatedly invalidating SwiftUI’s scene and command menus. Meter telemetry now has separate state, the application delegate keeps a stable model, and first-run setup waits until the window has appeared.

Soundboard files can now be replaced while audio is running without freeing data used by a callback. Recording start/stop actions serialize safely. Broadcast pipes use bounded, nonblocking writes so a stalled encoder cannot freeze the interface. SHOUTcast’s CRLF login response and secure Icecast’s TLS settings are handled explicitly.

What remains unverified

  • Physical microphone listening tests and virtual microphone reception in Discord, Zoom, OBS, or Logic Pro.
  • Process-tap permission transitions, protected content, and multi-process application capture.
  • Physical unplug/reconnect, Bluetooth format changes, sleep/wake, and clean-machine installer upgrade/removal.
  • Older supported macOS versions, Intel Macs, and public internet broadcast services. Broadcast tests used isolated local servers.
  • Developer ID signing, notarization, and clean-machine Gatekeeper validation. Signing credentials were not available.

Current boundaries

Each bus is stereo, and each output device has one assigned bus. The 16-channel driver is accessed through selected stereo pairs. Soundboard clips are limited to five minutes each and 256 MB of decoded audio in total. WAV takes use the standard 4 GB file limit.

Haunted Cavern uses the original narrow CardCore treatment; the separate wide/convolution treatment is not included. Broadcast title is set at connection time. SHOUTcast v2 and live metadata updates are not included. Some RTMP services require video, which this audio-only output does not provide.
