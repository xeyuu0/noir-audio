GETTING STARTED / 0.1.0 PREVIEW

A little setup.
A lot of possibility.

Choose an input, give your sound a destination, and make the mix your own.

Before you download: this is an Apple Silicon development preview. The app and driver bundles use ad-hoc signatures; the installer is unsigned. They are not Developer ID signed or notarized. The verified host is macOS 27.2; earlier supported macOS versions remain untested. Review the release notes and matching source.

Using a PC? Follow the Windows setup guide.

Install the Mac app

  1. Download the Mac disk image and open it in Finder. This build needs an M1 or later Mac and macOS 14.2 or later.
  2. Move NOIR Audio.app into Applications. If replacing an older copy, quit it first, then replace the app. Your session lives separately in Application Support.
  3. Open the app. macOS may block this unnotarized preview. If you decide to trust it after reviewing its source and checksum, follow Apple’s instructions for opening software you trust. Managed Macs may enforce additional restrictions.
  4. Run the setup assistant. Choose your microphone and physical headphones or output device. Audio stays stopped until you press Start audio.
Download the Mac preview ↓

Install virtual audio devices

Open Virtual Devices → Install / repair NOIR drivers, or use the separate driver installer. Quit audio applications before installing. macOS Installer requests administrator authorization. Restart afterward so Core Audio loads the new devices.

The package installs a stereo NOIR Microphone and a 16-channel NOIR Loopback. It does not change your system’s default audio device. Existing compatible BlackHole devices can also be selected.

Microphone + clips into voice chat

  1. In Audio Mixer, select your physical microphone on Input 1.
  2. Assign Main → NOIR Microphone and Monitor → your headphones.
  3. Enable the microphone’s Main send. Enable its Monitor send only if you want to hear yourself; use headphones to avoid feedback.
  4. Press Start audio. Allow microphone access when macOS asks. Select an effect or voice preset if you want one.
  5. In your receiving app, choose NOIR Microphone as input and your headphones as output. Confirm reception using that app’s input meter or test feature.
  6. Import clips into Soundboard and enable Soundboard → Main. Clip volume and monitoring remain independent.

Keep the chat app’s received audio out of the mix sent back to the same chat. NOIR blocks a direct hardware input-to-same-device return, but multi-app feedback loops still depend on your routing.

Bring Logic Pro into the mix

  1. In Logic Pro’s audio settings, choose NOIR Loopback as the output device. Send Logic’s stereo output to channels 1–2.
  2. In NOIR, select NOIR Loopback, channels 1–2 on an unused input strip.
  3. Enable that strip’s Monitor send to hear it through NOIR’s headphones. Enable its Main send to include it in the virtual microphone mix.
  4. Keep Main assigned to NOIR Microphone, and avoid returning the loopback input to the same loopback device.

For an internal recording, leave a bus without a hardware destination and select it in Recorder. These are setup instructions; reception in individual Logic Pro, Discord, and OBS versions still needs validation on your system.

Capture an application

Open Application Audio, refresh the list, choose your intended app, then press Start selected capture. macOS manages system-audio recording permission. Route the Application strip to the desired bus. Protected content may be silent, and apps with multiple helper processes may need loopback routing instead.

Record, replay, and broadcast

Recorder writes stereo 48 kHz, 24-bit WAV files from your chosen microphone stage or bus. Instant replay holds 5–120 seconds. Stop a recording before exporting an AAC copy. Interrupted WAV takes are recovered on the next launch when their files and recovery journals remain available.

Broadcasting uses a separately installed FFmpeg executable with the required encoders. Set an independent mix such as Aux 3, select FFmpeg, then configure your Icecast, SHOUTcast v1, or RTMP(S) endpoint. Secure endpoints verify certificates and hostnames; a custom PEM certificate authority can be selected for a private server. Confirm playback at a separate listener. Some RTMP services require video and reject audio-only streams.

Verify a download

Download SHA256SUMS.txt and compare its entry with the downloaded file’s SHA-256. In Terminal, from the folder containing the ZIP:

shasum -a 256 NOIR-Audio-0.1.0-macOS-arm64.zip

Checksums detect an incomplete or changed download. They are not a replacement for Developer ID signing or notarization.

Build from source

The source archive includes the Xcode project, original code, upstream source snapshots, licenses, and tests. You need Apple Silicon, Xcode with the macOS 26 SDK or newer, and XcodeGen. From the extracted source directory:

bash Scripts/build-drivers.sh
bash Scripts/build.sh
open 'dist/NOIR Audio.app'

Read README.md, Docs/Architecture.md, and Docs/Validation.md in the archive for the full engineering notes.

Remove the app or drivers

To remove the virtual devices, quit other audio applications, then use Virtual Devices → Remove NOIR drivers. macOS requests administrator authorization; restart afterward. This removes only NOIR’s two drivers and receipt, preserving other vendors’ drivers.

Quit NOIR and move its app to the Trash to remove the application. Your recordings and session data remain in their own folders. The default session location is ~/Library/Application Support/NOIR Audio; preserve it if you want to keep your settings and imported clips.
